# Требования проекта

## User Stories

| ID | История | Актор |
|----|---------|-------|
| US-01 | Как **Пользователь**, я хочу получать рекомендации через REST API, чтобы получать персонализированный контент | User |
| US-02 | Как **Пользователь**, я хочу получать рекомендации через Telegram Bot, чтобы получать контент в мессенджере | User |
| US-03 | Как **Менеджер**, я хочу создавать динамические правила, чтобы настраивать логику рекомендаций | Manager |
| US-04 | Как **Менеджер**, я хочу обновлять динамические правила, чтобы корректировать логику рекомендаций | Manager |
| US-05 | Как **Менеджер**, я хочу удалять динамические правила, чтобы управлять набором правил | Manager |
| US-06 | Как **Менеджер**, я хочу просматривать все динамические правила, чтобы контролировать систему | Manager |
| US-07 | Как **Менеджер**, я хочу просматривать статистику приложения, чтобы оценивать эффективность системы | Manager |
| US-08 | Как **Внешняя система**, я хочу очищать кеш рекомендаций, чтобы инвалидировать устаревшие данные | External System |
| US-09 | Как **Внешняя система**, я хочу получать информацию о приложении, чтобы мониторить его состояние | External System |

## Нефункциональные требования

| ID | Требование |
|----|------------|
| NFR-01 | Приложение должно запускаться в течение 30 секунд |
| NFR-02 | Время ответа REST API для получения рекомендаций должно быть менее 500 мс |
| NFR-03 | Кеш должен истекавать через 30 минут |
| NFR-04 | Приложение должно поддерживать минимум 100 одновременных пользователей |
| NFR-05 | Код должен проходить статический анализ Checkstyle без нарушений |
| NFR-06 | API должен иметь документацию OpenAPI/Swagger |
